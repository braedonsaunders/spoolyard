# Spoolyard 0.2.5

- Keep the same three-direction isometric grid in Paper and Model space. The model grid fills the viewport and follows pan, zoom, routing plane and fullscreen changes.
- Keep model-space pipe dimensions and labels readable in dark mode.
- Add an enter/exit fullscreen button at the top right of the editor header. Escape exits fullscreen.
- Order drawing tools as Select, Pan, Pipe, Insert, with V/H/P/I shortcuts. Insert opens the component palette; switching tools cancels pending placement.
- Keep ribbon controls from overlapping as the window narrows.

Validation: 69 regression tests pass, including distant model-space panning, all routing planes and the full zoom range. Browser interaction checks cover grid visibility, pan/zoom, light/dark themes, fullscreen entry/exit/Escape, component placement and saving, tool shortcuts and Paper view.

Desktop installers remain unsigned.

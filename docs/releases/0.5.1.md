# Spoolyard 0.5.1

Classic Spoolyard paper is the default again, with a large drawing heading, a simple bottom title block and a visible view label. The full material schedule remains available. Classic tables use the space freed when general notes move into the footer; longer notes continue above it.

The 0.5 series also adds independent item-number positions, held leader bends, per-label lettering controls, repeated line identifiers, explicit elevation visibility, valve callout order and editable hose routes. Offset constructions have configurable hatching, angle corners, radii and arrows. Check valves, unions, threaded nipples, camlock fittings and valve actuators have corrected symbols.

This patch makes the held construction corner work for planar offsets as well as rolling offsets. Drafting changes preserve physical coordinates, calculated dimensions and pipe cuts.

Validation: 305 automated tests and the production build pass. Native documents, SVG, PDF and DXF use the same drawing primitives.

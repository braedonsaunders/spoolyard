# Spoolyard 0.4.0

More control over issued drawings, with corrected joint fabrication and dimensioning.

- Link an adjacent `.piping` drawing at a continuation. Its embedded snapshot supplies thin reference geometry and optional dimensions without contributing material, cuts, welds or export sheets.
- Arrange nodes on isometric paper independently of plant coordinates and fabrication lengths. Positions survive save/reopen and are ignored by model-space and orthographic views.
- Draft dimensions between selected work points, component body faces or mating flange faces. Choose the extension direction and paper offset; measured lengths continue to come from the model. Automatic dimensions remain the default.
- Hold and reorder issued BOM item numbers. Explicitly retain legacy printed cell values while keeping calculated quantities and cut lengths available in Drawing setup.
- Choose component-face dimension chains, independent rounding for legacy drawings, stacked nominal-size labels and a north ellipse with compass ticks.
- Correct lap-joint stub-end takeouts, fitting-to-fitting weld merging, flange-face dimensions and bolting order by connected pipe size. Explicit flange connections no longer create phantom pipe cuts or welds. A tapped mating body can use lug bolts.
- Improve hoses, bought nipples, valve operators, equipment outlines, instrument bubbles, short connector layouts and flow arrows.

Includes the routing, component library, field-fit allowances, manufacturing checks, weld numbering, procurement descriptions and export improvements developed since 0.3.1.

Validation: 243 automated checks pass, TypeScript checks pass, and all 39 private verification drawings build, reopen and render without fabrication validation issues. These checks do not establish pixel-for-pixel equivalence with the issued reference drawings. Desktop installers remain unsigned.

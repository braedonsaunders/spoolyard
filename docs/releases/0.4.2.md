# Spoolyard 0.4.2

Includes the [0.4.0 drawing and fabrication improvements](https://github.com/braedonsaunders/spoolyard/releases/tag/v0.4.0) and the 0.4.1 cut-list correction.

Drafted dimensions now distinguish an end flange's own face from its mating face under either stored coordinate convention, including the gasket offset. Adding a drafted dimension to a vertical run also selects a horizontal extension direction so the new dimension is visible immediately.

Validation: 244 automated checks, TypeScript and production build pass. All 39 private verification drawings build and reopen without fabrication validation issues. Desktop installers remain unsigned. Exact visual equivalence to the issued reference set is not established by these checks.

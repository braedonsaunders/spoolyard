# Spoolyard 0.2.4

Built on `4d1b09d` (imperial block scale and inline pipe dimension editing).

- Preserve precise measurements when editing or cancelling imperial length fields. Exact fractions stay fractional; other values use decimal inches.
- Use feet, pounds and square feet for imperial material schedules in the editor, drawing, PDF and CSV. Small takeouts and root gaps retain their actual value.
- Match the PDF grid caption to the drawing's working units.
- Wait for IndexedDB transaction completion before reporting a browser save as successful. Close database connections after every operation.
- Serialize autosaves, include edits made during a pending save, and retain unsaved work after a failed write.
- Commit active fields before saving, switching drawings, returning Home or closing. Warn before a browser leaves with unsaved work.
- On desktop, write files atomically, retain the disk location when reopening from Recent, and finish saving before the window closes.
- Keep desktop startup file events until the editor is ready and clean up native listeners.
- Validate imported files before replacing the current drawing; retain unchanged imports in Recent.
- Show failed template/library/storage loads instead of silently substituting specifications or hiding errors.
- Add keyboard access to Recent drawings and in-app guidance for imperial scale, inline dimensions and saving.
- Require tests and the TypeScript production build before either web deployment or desktop packaging.

## Validation

- 66 unit/regression tests pass; TypeScript and the Vite production build pass.
- Chrome: imperial scale, exact and fractional dimension edits, cut editing, undo/redo, Home/reopen, reload, 3D and both themes.
- Browser failure injection: aborted IndexedDB transaction, failed-save retention/retry, active-field unload protection, and unavailable stainless template.
- Native macOS Electron: startup file association, autosave, Recent disk association, switching files with a pending edit, and closing with an active field. No renderer errors.
- Apple Silicon and Intel macOS DMG/ZIP packages built successfully. The packaged Apple Silicon app passed the same native save/switch/close checks.
- PDF, DWG, DXF, PCF, SVG, .piping and all three CSV exports download successfully. DXF/PCF round trips retain pipe cut measurements. DWG has the expected AutoCAD 2000 file signature.
- All four pages of the imperial PDF package rendered and visually inspected.

Windows and Linux installers are produced by the existing native CI jobs when released. Runtime testing above was on macOS and Chrome. Desktop signing remains unconfigured, as in previous releases.

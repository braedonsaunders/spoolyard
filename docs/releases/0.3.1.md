# Spoolyard 0.3.1

- Fix the app layout in the published web app and desktop installers. In 0.3.0 one editor style rule was left unclosed. Once the stylesheets were bundled, that swallowed the app's own stylesheet, so the page lost its full-height layout and its lettering. After switching tabs the drawing area grew far taller than the window, and the sheet scrolled out of view. Drawing setup was also unstyled.
- A test now fails the build if any stylesheet leaves a rule open. Release smoke checks run against the production build and confirm the app fits its window in its own lettering, before and after switching tabs.

All 0.3.0 changes are included.

Validation: 143 automated tests pass. The production build passed every field-feedback smoke check in Chrome at the Windows window size.

The published Windows installer was verified by SHA-256 and installed on the work computer. The installed app and the live site in Microsoft Edge 155 each passed all 15 checks with no page errors:
- the app fits its window in its own lettering, before and after switching tabs;
- new drawings use the production style, and lap-joint flanges are offered;
- a flanged ball valve needs no manual length and raises no fabrication checks;
- the valve lists two gaskets and eight `5/8"X3 1/4"` studs;
- a flange dropped on the open pipe end becomes the end and adds its gasket and four studs;
- the valve reads 40 % of its straight, and left-dragging empty canvas pans in Select;
- the drawing persists after a reload.

QA files were removed afterwards. Windows, macOS and Linux release builds, CI and the production web deployment all passed.

Desktop installers remain unsigned.

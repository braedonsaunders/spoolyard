# Spoolyard 0.6.0

A general-purpose overhaul. Drafting conventions that used to be fixed now follow published standards or explicit, documented settings with neutral defaults. The editor works like a CAD tool, and every output is checked against what CAD and fabrication software expect.

## Drafting
- Not-to-scale sheets are drafted on isometric paper laid on the sheet itself. Every bend, branch and end of pipe sits on a lattice point, every straight pipe is a whole number of cells, loops close, and parallel legs never merge. Plan and elevation views use a square lattice. The cell is set in Drawing setup (⅛″ to ⅜″).
- Symbols are chosen from component metadata rather than code names. Lettering, arrows, symbols and dimension tiers are sized in paper millimetres from one text height (2.5 mm default). Large-bore symbols are clamped to size classes. Welds sit at their true takeout on to-scale sheets. Field-fit welds get their own mark. Extension lines always run along plant axes.
- Title blocks come from templates. The built-in ISO 7200-style template scales uniformly to Letter, Tabloid, A3 and A4, and custom templates import and export as JSON. Sheet notes state NTS or the actual standard scale, and the view direction.
- Callouts and labels avoid each other automatically. Each piece can be picked, dragged, nudged and reset on its own. No issued sheet prints lettering over lettering: crowded material lists move to their own sheet ("SHEET n OF m"), and remaining labels move to clear margin space with leaders.
- North rotates the plan in quarter turns, and the north symbol shows the true angle.

## Fabrication
- Formed pipe bends are one piece: tangents plus arc, no welds. Close-coupled fittings are checked for root gap. The branch table chooses tee, reducing tee or olet. Eccentric reducers offset the small-end pipework by (D−d)/2.
- Field-fit ends, spool-break welds, socket-weld gaps (1/16″ default for new specifications) and weld spacing, including olets and welded attachments, follow documented rules.
- Fittings and bolting use each row's own class, face and pattern, and nothing silently falls back to Class 150. Butterfly valves distinguish wafer, lug and double-flanged bodies and API 609 Category A and B. Gaskets and bolt sets come from one source. Assumed values are flagged on the item and in the review.
- One material engine feeds the sheet, the CSV and the PCF. Overrides keep the calculated value and are flagged when they differ. A project profile holds stock length, order rounding, kerf, bend allowance, cut wording, feet thresholds, item order, weld numbering and NPS/DN notation.
- Library specifications were corrected against ASME B36.10M/B36.19M: walls and masses, stainless swage materials, and eccentric offsets ((D−d)/2 on all 1,416 rows).

## Editor
- Window and crossing selection, multi-selection editing, Move, Copy, Erase and clipboard paste.
- Object snaps, and a command line for typed lengths, `N 10'` and `@E,N,EL`.
- Measure, a live plant coordinate readout, zoom window, zoom extents and zoom previous.
- Selection cycling with Tab, F1/F3/F7/F8/F9, and Esc and right-click that behave as in CAD.
- One undo step per edit. Drafting aids are preferences, not document edits.
- Ctrl/⌘+S saves the file and autosave keeps a recovery copy. Import replaces the drawing and lists warnings.
- The properties panel is rebuilt as one consistent design, with key lengths, Fabrication and Annotation tabs, and property search.
- Rendering is incremental, and drawings are a pure function of their inputs.

## Files
- PCF follows the standard: SKEYs, end types, item codes, plant coordinates, one header per pipeline. Third-party PCFs import, with unknown parts brought in as generic components and warnings. A `.piping` companion file (ZIP) gives an exact round trip.
- DXF is a complete AutoCAD R2000 file: tables, blocks for every symbol, title-block and BOM attributes, real linetypes, arcs, MTEXT and wipeouts. It audits clean in ezdxf and converts to DWG.
- PDF packages have one sheet per spool and view, searchable CAD lettering, paper-correct pen weights, metadata and bookmarks. CSV schedules gain decimal columns, a labour schedule and a UTF-8 BOM. SVG carries true paper size.

## Desktop
- Electron 44. Save is restricted to files the user opened or chose. Strict content security policy. Crash recovery. Dialogs open in the last drawing's folder. Smaller package.
- DWG export: GNU LibreDWG 0.14 (GPL-3.0-or-later). Source, build recipe and a reproducible build script are in `public/dwg-export/SOURCE.md` and `scripts/build-dwg-export.sh`. The LibreDWG 0.14 source tarball is attached to this release.

## Notes for checkers
- Lug-bolt lengths use Spoolyard's lug-body convention (flange + gasket + nut + engagement + projection). Each lug row is flagged to confirm against the valve maker's chart.
- The slip-on flange set-back follows the lesser of wall and 1/4″ fillet size of ASME B31.3 Fig. 328.5.2B plus a 1/16″ convention. Confirm against your code edition.

Validation: 553 automated tests, TypeScript checking, end-to-end production jobs hand-checked against ASME B16.5/B16.9/B16.10/B16.11/B36.10M/B36.19M and MSS SP-97, ezdxf audit, DWG read-back, and desktop and embed automation.

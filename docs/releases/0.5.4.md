# Spoolyard 0.5.4

Material tables can retain independently editable item, quantity and size column widths. Descriptions use the remaining space, while column changes preserve lettering size and native-file persistence. Drawing setup provides the column controls and a return to automatic widths.

Includes the restored classic Spoolyard paper, linked adjacent-point dimensions, caption-only supports, footer-safe material tables and approximate dimension marks from 0.5.0–0.5.3. Validation: 310 automated tests and TypeScript checking.

# Spoolyard 0.5.2

Classic paper keeps tall material tables and continued notes above its footer. Every material column reserves space from the drawing, and long headings fit beside the table without losing their text. The north marker follows the table actually printed on the sheet.

Existing supports can use an arrowed caption instead of a new support symbol. The support remains attached to its physical pipe point, and the drawing choice persists in native files.

Dimensions can measure to an adjacent work point using the linked reference geometry. These anchors persist in native files and are removed when their reference is removed.

All 0.5.0 and 0.5.1 drafting controls are included. Validation: 308 automated tests, including dense material tables, long notes, complete headings and support-caption round trips.
